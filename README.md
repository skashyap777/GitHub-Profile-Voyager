# 🚀 GitHub Profile Voyager

**GitHub Profile Voyager** is a premium, high-performance web application designed to explore the GitHub universe. It provides deep insights into user profiles, repository trends, and developer statistics with a stunning, modern dark-mode aesthetic.

## ✨ Features

- **Profile Explorer**: Search any GitHub user to view their detailed profile, including bio, location, join date, and public stats.
- **Language Constellation**: Visualize the primary languages used in a developer's repositories with precise percentage distributions.
- **Repository Showdown**: Compare two developers side-by-side to see who has more stars, forks, or followers.
- **Analytics Dashboard**: Get deep insights into activity patterns, repository growth over time, and a contribution calendar visualization.
- **Explore Galaxy**: Discover trending repositories across multiple languages (JavaScript, Python, Rust, etc.) and find the top developers globally.

## 🛠️ Built With

- **HTML5 & Semantic Elements**: For structured, accessible content.
- **Tailwind CSS**: For a responsive, premium glassmorphism design.
- **Vanilla JavaScript**: Lightweight and fast logic without heavy framework overhead.
- **GitHub REST API**: Real-time data fetching from the source of truth.
- **Lucide/Feather Icons**: Clean, consistent iconography throughout the app.
- **Chart.js**: Dynamic and interactive data visualizations.
